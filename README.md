# mcp-ui-design-demo

------
PaymentButton.tsx
UI: یک دکمه پرداخت با آیکون کارت اعتباری (Digche) با طراحی ساده و تمیز دیگ. این دکمه برای عملیات پرداخت کاربر استفاده می‌شود.

Dig component: این UI به سبک دکلمه Button دیگ (Dig) نزدیک است و از پایهٔ Button موجود در طراحی دیگ الهام گرفته است تا در پروژه به راحتی با معماری Dig هماهنگ باشد.

Digche icon: از آیکون credit-card در Digche با سبک Linear استفاده شده است تا نمایی واضح از کارت پرداخت ارائه دهد.

Why: دکمه‌ای واضح برای پرداخت با آیکون قابل فهم، مناسب برای صفحات checkout و پرداخت.
